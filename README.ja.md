# AIFlow

**ショートカット一つで全てのAIを。** どのアプリからでもGPT、Claude、Gemini、ローカルLLMと対話できるローカルデスクトップAIハブ — ナレッジベース、マルチステップエージェント、ワークフロー自動化まで。

[English](README.md) | [Korean](README.ko.md) | [Chinese](README.zh.md)

---

## AIFlowとは？

AIFlowは複数のAIプロバイダーを一つにまとめた**Windowsデスクトップアプリ**です。どのアプリでも`Alt+Space`を押すとAIFlowが表示され、質問するとリアルタイムストリーミング応答とコスト表示が得られます。

**クラウドアカウント不要。データ収集なし。全てがPC上に保存されます。**

## 主な機能

### コアチャット
| 機能 | 説明 |
|------|------|
| **グローバルショートカット** (`Alt+Space`) | どのアプリからでもAIFlowを呼び出し |
| **マルチプロバイダー** | GPT-4o、Claude Sonnet、Gemini Flash + 8社以上（合計11社） |
| **APIキー検証** | 保存前にプロバイダーAPIで有効性を自動検証 |

| **暗号化DB** | SQLCipher AES-256で全会話を暗号化 |
| **AIペルソナ** | 6種内蔵（開発者、ライター、翻訳者、アナリスト、法務、要約） |
| **プロンプトライブラリ** | 保存、タグ、検索 + `{{変数}}`スロット対応 |

| **ファイルドラッグ＆ドロップ** | PDF、TXT、MD、コード、画像をAIチャットに直接送信 |
| **クリップボード→AI** (`Alt+Shift+A`) | どのアプリからでもクリップボード内容をAIに即時送信 |
| **スクリーンショット→AI** (`Ctrl+Shift+S`) | スクリーンショットをVision AIに送信 |
| **システムトレイ** | バックグラウンド実行 + クイックアクセストレイメニュー |

## 技術スタック

| レイヤー | 技術 |
|----------|------|
| デスクトップ | Tauri 2 (Rustバックエンド) |
| フロントエンド | React 19 + TypeScript + Tailwind CSS v4 |
| データベース | SQLite + SQLCipher (AES-256、PBKDF2-SHA512 256k回) |
| 全文検索 | SQLite FTS5 (ナレッジベースRAG) |
| APIキー | Windows資格情報マネージャー (OSキーチェーン) |
| 状態管理 | Zustand |
| ストリーミング | Tauri ipc::Channel |
| AI呼び出し | Rust reqwest (CORSなし、キーはフロントエンドに渡らない) |
| i18n | react-i18next |

## はじめに

### 前提条件

- **Windows 10 21H2+** または **Windows 11**
- AIのAPIキー1つ以上 (OpenAI、Anthropic、Google)

### リリースからインストール

1. [GitHub Releases](https://github.com/sodam-ai/ai-flow/releases)から最新の`.msi`をダウンロード
2. インストーラーを実行
3. システムトレイにAIFlowが表示される
4. `Alt+Space`でオーバーレイを開く
5. **設定**でAPIキーを追加

### ソースからビルド

#### 要件

- Rustツールチェーン (MSVCターゲット): `rustup default stable`
- Visual Studio Build Tools (C++ワークロード)
- Strawberry Perl: `choco install strawberryperl -y` (SQLCipherに必要)
- Node.js 20+: `choco install nodejs-lts -y`

#### 手順

```bash
# リポジトリをクローン
git clone https://github.com/sodam-ai/ai-flow.git
cd ai-flow

# フロントエンド依存関係をインストール
npm install

# 開発モードで実行
npm run tauri:dev

# プロダクションビルド (.msiインストーラー)
npm run tauri:build
```

## 主要機能の使い方

### ナレッジベース (RAG)

1. サイドバーの**ナレッジベース**（データベースアイコン）をクリック
2. **新規ナレッジベース**をクリックして作成
3. インデックス化するファイルを選択（`.txt`、`.md`、`.py`、`.ts`、`.rs`、`.json`など）
4. 検索ボックスでドキュメントをクエリ — 結果に一致テキストがハイライト
5. AIエージェントはタスク実行中にナレッジベースを自動検索可能

### AIエージェント

1. サイドバーの**AIエージェント**（ビーカーアイコン）をクリック
2. 入力ボックスに目標を入力（例：「ナレッジベースの全ドキュメントを要約して」）
3. エージェントがステップを計画し、一つずつ実行
4. ファイル書き込みやワークフロー実行が必要なステップは**承認ゲート**を表示 — 進む前に確認
5. いつでもエージェントをキャンセル可能

### 会話ブランチング

1. 会話でメッセージにホバー
2. **フォーク**ボタンをクリックしてその地点からブランチ
3. その地点までの全メッセージがコピーされた新しい会話が作成される
4. 元のスレッドを失わずに異なるAI応答を探索

### ワークフロー書き出し/読み込み

1. **ワークフロービルダー**を開いてワークフローを選択
2. **書き出し**をクリックして`.json`ファイルをダウンロード
3. 別の端末で**読み込み**をクリックしてファイルを選択
4. 全ステップが復元されたワークフローが再作成される

## 環境変数

AIFlowは`.env`ファイルを**必要としません**。全シークレットはOSキーチェーンに保存されます。

| 変数 | 目的 | 設定場所 |
|------|------|----------|
| AI APIキー | プロバイダー認証 | OSキーチェーン（設定UI） |
| DBマスターキー | データベース暗号化 | OSキーチェーン（初回起動時に自動生成） |
| デバイスID | ライセンス検証 | OSキーチェーン（ランダムUUID） |

## セキュリティ

| 領域 | 実装 |
|------|------|
| APIキー保管 | OSキーチェーンのみ — コード、ファイル、DBには絶対保存しない |
| APIキー検証 | 保存前にライブAPI呼び出しで検証 |
| データベース | SQLCipher AES-256 + PBKDF2-SHA512 (256,000回) |
| DBマスターキー | 自動生成ランダム32バイトキー、OSキーチェーンに保存 |
| IPCパラメータ | フロントエンドZod検証 + バックエンドRust型システム |
| ストリーミング | Tauri ipc::Channel（EventSystemではない）、キャンセル対応 |
| CSP | `default-src 'self'`（unsafe-evalなし） |
| 監査ログ | 不変のINSERT専用ログ（キーイベント、ストリームイベント） |
| プライバシーモード | 100%ローカルPIIスキャナー — データは端末外に出ない |
| テンプレートインジェクション | `{{input}}`値、AI置換前にサニタイズ |
| FTS5インジェクション | 検索クエリをダブルクォートで囲み、特殊文字を除去 |
| パスセキュリティ | 全MCPファイルパスに`canonicalize()`適用（シンボリックリンクトラバーサル防止） |
| 入力制限 | 全テキスト入力に最大長検証（目標: 2KB、クエリ: 500文字） |
| ファイルアクセス | 絶対パス確認 + 拡張子許可リスト + 5MBサイズ制限（KB） |

# AIFlow

Windows向けのローカルデスクトップAIチャットアプリケーションです。複数のAIプロバイダーへの接続、会話の管理、カスタムAIペルソナの作成が可能です。APIキーはWindows資格情報マネージャー（OSキーチェーン）に安全に保存され、データベースには一切保存されません。

**バージョン:** 0.1.0 | **ライセンス:** SoDam AI Studio | **プラットフォーム:** Windows 10/11

## 機能一覧

### 対応AIプロバイダー

- **OpenAI** — GPT-4.1、o3、o4-mini
- **Anthropic** — Claude 4.6（Sonnet、Haiku、Opus）
- **Google Gemini** — 2.5 Pro
- **Ollama** — ローカルモデルをオフラインで実行（APIキー不要）
- **Mistral** — Mistral Large、Codestral など
- **Groq** — 超高速推論
- **DeepSeek** — DeepSeek-V3、DeepSeek-R1
- **Cohere** — Command R+
- **xAI** — Grok
- **Azure OpenAI** — Azure経由のエンタープライズグレードOpenAI
- **OpenAI互換** — OpenAI仕様の任意エンドポイント（LM Studio、vLLM など）

### チャット機能

- リアルタイムストリーミングレスポンス
- メッセージごと・セッションごとのコスト表示（USD・KRW両対応）
- 会話のピン留め、名前変更、削除
- 会話履歴をローカルのSQLiteデータベースに保存

### ペルソナシステム

- 名前・アバター・システムプロンプトでカスタムAI人格を作成
- ペルソナごとにデフォルトモデルを設定可能
- 会話ごとにペルソナを切り替え可能

### プロンプトライブラリ

- 再利用可能なプロンプトテンプレートを保存
- `{{変数}}` スロットによる穴埋め形式プロンプト
- カテゴリ別テンプレート管理

### 生産性機能

- **Alt+Shift+A** グローバルショートカット：クリップボードの内容を取得し、AIFlowを即時起動
- ダークモード対応
- Ollamaローカルモデルによるオフラインサポート
- システムトレイアイコンからのクイックアクセス

### セキュリティ

- APIキーは**Windows資格情報マネージャー（OSキーチェーン）のみ**に保存
- SQLiteデータベースやログファイルにはキーを一切書き込まない
- 外部APIリクエストはHTTPSのみ使用
- すべての送信接続にSSRF（サーバーサイドリクエストフォージェリ）防御を適用
- SQLインジェクション対策としてパラメータ化SQLを使用

## はじめての方へ（プログラミング未経験者向け）

> このセクションは、プログラミングやコードを一度も触ったことがない方のために書かれています。
> 開発者の方は [開発者向けセットアップ](#開発者向けセットアップ) へお進みください。

---

### ステップ 1 — AIFlowをダウンロードする

1. このリポジトリの [Releases（リリース）ページ](../../releases) を開きます。
2. `AIFlow_0.1.0_x64-setup.exe` という名前のファイルをダウンロードします。
3. ダウンロードしたファイルをダブルクリックし、インストーラーの指示に従って進めます。
4. インストールが完了すると、スタートメニューとデスクトップにAIFlowが表示されます。

> **補足：** ダウンロードしたファイルを実行すると「このアプリを実行しますか？」というWindowsの確認画面が表示されることがあります。「実行」または「はい」をクリックしてください。

---

### ステップ 2 — AIFlowを開く

1. デスクトップのAIFlowアイコンをダブルクリックします（または、スタートメニューで「AIFlow」と検索してください）。
2. アプリケーションウィンドウが開きます。

---

### ステップ 3 — APIキーを登録する

AIと会話するには、プロバイダーからAPIキーを取得する必要があります。APIキーとは、AIFlowがそのAIサービスと通信するための「パスワード」のようなものです。

**無料または有料のAPIキーの取得先：**

| プロバイダー | キー取得URL | 備考 |
|------------|-----------|------|
| OpenAI | https://platform.openai.com/api-keys | 有料（従量制） |
| Anthropic | https://console.anthropic.com/account/keys | 有料（従量制） |
| Google Gemini | https://aistudio.google.com/app/apikey | 無料枠あり |
| Groq | https://console.groq.com/keys | 無料枠あり（高速） |

**AIFlowにキーを登録する手順：**

1. ウィンドウ左下の **設定アイコン（歯車マーク）** をクリックします。
2. 使用したいプロバイダー（例：「OpenAI」）を選択します。
3. APIキーをテキストフィールドに貼り付けます。
4. **保存** をクリックします。

キーはWindowsが Wi-Fiパスワードを保存するのと同じ場所（Windows資格情報マネージャー）に安全に保存されます。キーがコンピューターの外に平文で送出されることは一切ありません。

---

### ステップ 4 — チャットを始める

1. 左サイドバーの **新しい会話** をクリックします。
2. ドロップダウンメニューからモデルを選択します（例：「gpt-4.1」）。
3. メッセージを入力して **Enter キー** を押すか、**送信ボタン** をクリックします。

これだけです。AIFlowは通常のチャットアプリと同じように操作できます。メッセージを送るとAIが返答します。

---

### ステップ 5 — クイックショートカットを使う（オプション）

何かのテキスト、コード、エラーメッセージなどをコピーして、すぐにAIFlowに送りたい場合：

1. 通常どおり **Ctrl+C** でテキストをコピーします。
2. **Alt+Shift+A** を押します。
3. コピーしたテキストが入力済みの状態でAIFlowが開きます。

---

### APIキーを無料で入手する方法（Groqの例）

1. https://console.groq.com/keys をブラウザで開きます。
2. Googleアカウントなどでサインアップ（無料）します。
3. 「Create API Key」ボタンをクリックします。
4. 表示されたキー（`gsk_` で始まる長い文字列）をコピーします。
5. AIFlowの設定画面を開き、「Groq」を選択してキーを貼り付け、保存します。

以上でGroqの超高速AIが無料で使えます。

## 開発者向けセットアップ

### 1. リポジトリをクローン

```bash
git clone <repository-url>
cd ai-flow
```

### 2. Node.js依存関係をインストール

```bash
npm install
```

### 3. Rustをインストール（未インストールの場合）

```bash
# Windows（PowerShell）
winget install Rustlang.Rustup
# または https://rustup.rs にアクセスしてインストーラーを使用
```

インストール後、ターミナルを再起動して確認します：

```bash
rustc --version   # 1.77以上が表示されることを確認
cargo --version
```

### 4. 環境ファイルをコピー

```bash
cp .env.example .env
```

必要に応じて `.env` を編集してください（詳細は [環境変数](#環境変数) を参照）。

### 5. 開発モードで起動

```bash
npm run dev
```

このコマンドにより、Vite開発サーバー（ポート1420）とTauriウィンドウが同時に起動します。Reactフロントエンドはホットリロードに対応しており、Rust側の変更はCargoの再コンパイルが必要です。

## 環境変数

アプリを実行する前に、`.env.example` を `.env` にコピーしてください。実際のAPIキーをバージョン管理システムにコミットしないよう注意してください。

```
# .env.example

# Tauri開発用ポート（デフォルト: 1420）
VITE_DEV_PORT=1420

# 1に設定すると、TauriバックエンドなしでブラウザのみのモックUIを起動
TAURI_MOCK=

# E2Eスイートでのキーチェーンテストを有効化
KEYCHAIN_TEST=
```

AIプロバイダーのAPIキーはすべて、実行時に設定UIから管理し、OSキーチェーンに保存します。環境変数として設定したり、`.env` ファイルに記述したりしないでください。

## APIキーの登録方法

APIキーは、環境変数や設定ファイルではなく、AIFlow内の設定パネルから登録します。

1. AIFlowを開きます。
2. ウィンドウ左下の **設定アイコン** をクリックします。
3. **プロバイダー** セクションで、設定したいプロバイダーを探します。
4. プロバイダー名をクリックして設定を展開します。
5. **APIキー** フィールドにキーを貼り付けます。
6. **保存** をクリックします。

AIFlowは即座にキーを **Windows資格情報マネージャー**（`コントロールパネル > 資格情報マネージャー > Windows資格情報`）に保存します。いつでもそちらで確認・削除が可能です。

キーをAIFlowから削除するには：設定を開き、プロバイダーを選択し、**キーを削除** をクリックします。

## Ollamaで無料ローカルAIを使う方法

Ollamaを使うと、大規模言語モデルを自分のコンピューター上でローカル実行できます。APIキー不要、インターネット接続不要、利用料金も発生しません。

### Ollamaのインストール

1. https://ollama.com/download/windows からOllamaをダウンロードします。
2. インストーラーを実行します。
3. OllamaはバックグラウンドサービスとしてURL `http://localhost:11434` で起動します。

### モデルのダウンロード

コマンドプロンプトまたはPowerShellを開き、以下のコマンドを実行します：

```bash
# 小型・高速モデル（RAM約4GB必要）
ollama pull llama3.2

# より高性能な大型モデル（RAM約8GB必要）
ollama pull llama3.1:8b

# コード特化モデル
ollama pull codellama
```

> **補足（初心者向け）：** コマンドプロンプトは、スタートメニューで「cmd」と検索して開きます。上のコマンドをコピーして貼り付け（右クリック→貼り付け）し、Enterキーを押してください。

### AIFlowでOllamaを接続する

1. AIFlowの設定を開きます。
2. プロバイダーリストから **Ollama** を選択します。
3. ベースURLはデフォルトで `http://localhost:11434` に設定されています。Ollamaのポートを変更していない限り、そのままにしてください。
4. **保存** をクリックします。
5. 会話画面でモデルドロップダウンを開き、Ollamaセクションのモデルを選択します。

Ollamaのモデルはすべてご自身のマシン上で実行されます。外部サーバーにデータが送信されることはありません。

## セキュリティについて

AIFlowは、機密性の高い認証情報を扱うにあたり、セキュリティを最優先に設計されています。

### APIキーが絶対に漏れない理由

AIFlowがAPIキーを安全に管理できるのは、以下の仕組みによるものです：

- APIキーは**Windows資格情報マネージャー（OSキーチェーンAPI）のみ**に保存されます。
- SQLiteデータベース、ログファイル、設定ファイル、環境変数には**一切書き込まれません**。
- 指定されたAIプロバイダーのエンドポイント以外のサーバーには**送信されません**。
- `コントロールパネル > 資格情報マネージャー > Windows資格情報` でいつでも保存済みキーの確認・編集・削除が可能です。

Windows資格情報マネージャーはWindowsがWi-Fiパスワードを保存する仕組みと同じです。Windowsへのログインパスワードなしでは他のユーザーがアクセスできません。

### ネットワーク通信

- 外部APIリクエストはすべてHTTPSのみを使用します。AIプロバイダーへの平文HTTP接続はブロックされます。
- SSRF（サーバーサイドリクエストフォージェリ）攻撃を防ぐため、送信先はアクセスリストで検証されます。
- AIFlowはテレメトリー、アナリティクス、利用データの収集・送信を一切行いません。

### データベース

- すべてのSQLクエリはパラメータ化ステートメントを使用しています。コードベース内でSQLへの生の文字列補間は使用されていません。
- SQLiteデータベースには会話履歴と設定のみが保存されます。シークレット（秘密情報）は一切含まれません。

### 依存関係の脆弱性診断

```bash
npm run test:security
```

このコマンドを実行することで、RustとNode.jsの依存関係ツリーを既知のCVE（脆弱性）に対してチェックできます。定期的な実行を推奨します。

## コントリビューション（貢献方法）

コントリビューション（Pull Request、バグ報告、機能提案）を歓迎します。以下の手順に従ってください。

### コードの変更・機能追加

1. リポジトリを **フォーク** し、`main` から新しいブランチを作成します。

   ```bash
   git checkout -b feature/your-feature-name
   ```

2. **変更を加えます。** コミットは目的ごとに小さくまとめてください。

3. Pull Requestを開く前に **テストスイートを実行** してください。

   ```bash
   npm run test:all
   ```

4. **リンターと型チェックを実行** してください。

   ```bash
   npm run lint
   npm run typecheck
   ```

5. `main` に対して **Pull Requestを開きます。** 変更内容と変更理由を明記してください。

### コードスタイル

- TypeScript：既存のESLint設定（`eslint.config.js`）に従ってください。
- Rust：コミット前に `cargo fmt` および `cargo clippy` を実行してください。
- コミットメッセージ：命令形を使用してください（例：`Add feature X`、`Fix bug in Y`）。

### バグの報告

## 1. 제품 개요

### 한 줄 요약
**어디서든 단축키 하나**로 GPT·Claude·Gemini·로컬 LLM을 동시에 쓰고, AI가 자동으로 최적 모델을 선택하며, 개인정보를 보호하고, MCP로 내 PC까지 연결하는 — **개인용 AI 통합 데스크톱 허브**.

### 해결하는 문제
| 페인포인트 | 현재 상황 | AIFlow 해결책 |
|-----------|---------|-------------|
| 탭 전환 피로 | ChatGPT·Claude·Gemini마다 브라우저 탭 | 단축키 하나로 모든 AI를 하나의 창에서 |
| 반복 프롬프트 | 같은 프롬프트를 메모장에서 매번 복사 | 프롬프트 저장고 + 변수 슬롯 자동완성 |
| API 키 불안 | 여러 서비스에 API 키 분산, 보안 걱정 | OS 키체인 + DB 암호화(AES-256) |
| 어떤 AI가 최적인지 모름 | 매번 수동으로 AI 선택 | 스마트 라우팅 — 비용·속도·품질 자동 최적화 |
| AI에 개인정보 노출 우려 | 직접 입력 전에 민감정보 확인 불가 | PII 자동 감지 + 마스킹 (570+ 패턴) |
| 자동화 장벽 | 여러 AI를 연결하려면 코드 필수 | 드래그앤드롭 워크플로우 빌더 |
| 로컬 LLM 진입장벽 | Ollama/LM Studio 따로 설치 후 연결 | 앱 내 자동 감지 + 원클릭 연결 |
| AI에 내 파일 전달 불편 | PDF·문서를 매번 텍스트로 변환 후 붙여넣기 | 파일 드래그앤드롭 → AI에 즉시 전달 |

## 2. 사용자

### 주요 사용자
- **누구**: AI 입문자 및 바이브코더 (AI를 매일 쓰지만 서버/코딩은 모르는 개인)
- **상황**: 집이나 사무실 Windows PC에서 매일 2~5개의 AI 도구를 번갈아 사용
- **목표**: 탭 전환 없이, 코드 없이, 비용 걱정 없이, 개인정보 걱정 없이 AI를 최대한 활용

### 사용자 시나리오

**시나리오 1 — 글로벌 단축키 + 스마트 라우팅 (v3.0 신규)**
1. 사용자가 Word에서 문서를 작성하다 막힌다
2. `Alt+Space` → AIFlow 오버레이 출현
3. "라우팅: 자동" 설정 → AIFlow가 질문 복잡도 분석 → 단순 질문은 Gemini Flash(저렴), 복잡한 질문은 Claude Sonnet으로 자동 전달
4. 응답 아래에 "예상보다 42% 저렴하게 처리했습니다 ($0.0014)" 표시

**시나리오 2 — 프라이버시 모드 + AI 분석 (v3.0 신규)**
1. 직원 평가서(이름·주민번호·전화번호 포함)를 AI로 분석해야 함
2. 파일 드래그앤드롭 → "프라이버시 모드: ON" 토글
3. AIFlow가 OpenRedaction으로 PII 자동 감지 → 마스킹 미리보기 표시
4. 확인 → [홍길동 → 직원A], [010-1234-5678 → ***-****-****] 처리 후 AI 전송
5. 분석 결과 수신 — 개인정보는 AI에 전달되지 않음

**시나리오 3 — 브라우저 확장 → AIFlow 연동 (v3.0 신규, Phase 2)**
1. Chrome에서 긴 영문 기사를 읽다가 요약이 필요함
2. 브라우저 확장 클릭 → "AIFlow로 보내기" → 현재 페이지 텍스트 자동 추출
3. AIFlow 오버레이 자동 소환 + 추출된 텍스트 자동 첨부
4. "핵심 3줄 요약해줘" → 응답 확인

**시나리오 4 — AI 페르소나 전환 (v3.0 신규)**
1. 사용자가 코드 리뷰 요청 → "시니어 개발자 페르소나" 선택
2. 같은 Claude Sonnet이지만 "TypeScript 전문 시니어 개발자, 한국어, 코드는 반드시 예시 포함" 시스템 프롬프트 자동 prepend
3. 블로그 글 작성 시 → "카피라이터 페르소나"로 전환 — 완전히 다른 말투와 구조로 응답

**시나리오 5 — 배치 처리 큐 (v3.0 신규)**
1. 번역할 TXT 파일 50개가 폴더에 있음
2. 폴더 드래그앤드롭 → "배치 처리" → "각 파일을 영어로 번역해줘" 프롬프트 설정
3. AIFlow가 파일 하나씩 순서대로 AI 전송 → 각 파일의 번역 결과를 별도 파일로 저장
4. 작업 중 트레이에 상주, 완료 시 시스템 알림

## 3. 핵심 기능 (전체 로드맵)

### Phase 1a — 핵심 MVP (즉시 가치, ~1주)
| 기능 | 설명 | 복잡도 |
|------|------|--------|
| **AI Provider 연결** | GPT-4o, Claude Sonnet 4.6, Gemini 1.5 Flash API 키 → OS 키체인에 암호화 저장 + **저장 시 경량 API 호출로 유효성 검증** | 간단 |
| **단일 AI 채팅** | 1개 AI와 실시간 스트리밍 대화 + **스트림 취소 버튼** | 보통 |
| **실시간 비용 표시** | 메시지마다 토큰 수 + 예상 비용(USD/KRW 병행) | 간단 |
| **SQLCipher DB 암호화** | AES-256 + PBKDF2-SHA512 25만 반복 + 기기별 랜덤 솔트 | 보통 |
| **IPC Zod 검증** | 모든 invoke 파라미터 Zod 스키마 검증 | 간단 |
| **기본 UI** | 사이드바, 다크모드 기본, 설정 화면 (11개 프로바이더) | 간단 |
| **채팅 히스토리** | 대화 목록, 핀 고정, 이름 변경, 메시지 페이지네이션 (50개씩) | 간단 |
| **i18n 기반** | react-i18next 적용 — 한국어 + 영어 2개 언어 | 간단 |
| **감사 로그** | AuditLog INSERT 전용 trigger (UPDATE/DELETE 차단) | 간단 |

## 4. 스마트 AI 라우팅 엔진 (v3.0 핵심 신기능)

### 라우팅 전략
```
사용자 입력 분석
  → 복잡도 점수 계산 (0~100)
  → 라우팅 전략 선택:
    [저복잡도 0~30] → Gemini Flash (저비용)
    [중복잡도 31~70] → Claude Haiku 또는 GPT-4o-mini
    [고복잡도 71~100] → Claude Sonnet / GPT-4o
    [실패] → 다음 후보 모델로 자동 폴백
```

### 복잡도 판단 기준
| 요소 | 낮은 복잡도 | 높은 복잡도 |
|------|-----------|-----------|
| 질문 길이 | 50자 미만 | 200자 초과 |
| 파일 첨부 | 없음 | PDF 등 첨부 |
| 코드 포함 여부 | 없음 | 코드 분석/생성 |
| 추론 요구 | 단순 조회 | 다단계 분석 |

### 사용자 라우팅 프리셋
- **비용 절약 모드**: 가능한 한 저렴한 모델 먼저 시도
- **품질 우선 모드**: 항상 최고 모델 사용
- **균형 모드 (기본)**: 복잡도 기반 자동 선택
- **프라이버시 모드**: 민감 내용은 무조건 로컬 LLM으로

## 5. 프라이버시 모드 (v3.0 핵심 신기능)

### PII 감지 패턴 (OpenRedaction 기반)
| 카테고리 | 감지 항목 | 한국 특화 |
|---------|---------|---------|
| 개인 식별 | 이름, 생년월일, 여권번호 | 주민등록번호, 외국인등록번호 |
| 연락처 | 이메일, 전화번호 | 한국 전화번호 (010-XXXX-XXXX) |
| 금융 | 신용카드번호, 계좌번호 | 한국 은행 계좌 형식 |
| 위치 | 주소, 우편번호 | 한국 주소 형식 (도·시·구·동) |
| 의료 | 진단명, 처방약 | 한국 의료보험 번호 |

### 동작 방식
```
파일/텍스트 입력
  → OpenRedaction (로컬 JS, 인터넷 없이 동작)
  → 감지된 PII 목록 + 미리보기 표시
  → 사용자 확인 (마스킹 / 무시 / 취소)
  → 마스킹된 텍스트만 AI에 전송
  → AI 응답에 마스킹 역치환 (옵션)
```

## 7. 사용자 흐름 (User Flow)

### 핵심 흐름 — 글로벌 단축키 + AI 대화 (Phase 1)
```
어떤 앱에서든 Alt+Space
  → AIFlow 오버레이 출현
  → AI 선택 (GPT-4o / Claude / Gemini)
  → 스트리밍 응답 + 비용 표시 (USD + KRW)
  → [복사 / 파일 저장 / 중지] → ESC로 닫기
```

### 핵심 흐름 — 스마트 라우팅 (Phase 2)
```
어떤 앱에서든 Alt+Space
  → AIFlow 오버레이 출현
  → [라우팅: 자동] → 질문 분석 → 최적 AI 자동 선택
  → 스트리밍 응답 + 비용 표시 + 절감액 표시
  → [복사 / 파일 저장 / 다른 AI로 재시도] → ESC로 닫기
```

### 핵심 흐름 — 프라이버시 모드
```
민감 파일 드래그앤드롭
  → 프라이버시 모드 ON
  → PII 감지 결과 미리보기 (몇 초)
  → 사용자 확인 → 마스킹 후 AI 전송
  → 응답 수신 (개인정보 없는 안전한 전송 완료)
```

### 핵심 흐름 — 브라우저 확장 (Phase 2)
```
Chrome/Edge에서 기사 읽다가 확장 클릭
  → 현재 탭 콘텐츠 자동 추출
  → AIFlow 오버레이 자동 소환 + 콘텐츠 첨부
  → 질문 입력 → AI 응답 → 결과 저장
```

### 상세 흐름 — 첫 실행 (2분 온보딩, v4.0 간소화)
1. **언어 선택** → 한국어 / English (앱 전체 언어 설정)
2. **API 키 연결** → 최소 1개 프로바이더 필수 → OS 키체인에 저장 + **경량 API 호출로 즉시 유효성 검증**
3. **첫 AI 대화** → "안녕하세요! AIFlow입니다" 자동 메시지로 즉시 체험 + `Alt+Space` 단축키 안내

> v3.1에서 v4.0 변경: 5단계(페르소나 선택, 라우팅 설정 포함) → 3단계로 축소.
> 페르소나와 라우팅은 Phase 1에 불필요하므로 사용 중 자연스럽게 안내 (툴팁, 명령 팔레트 제안).

## 8. 성공 기준 (v4.0 재작성)

### Phase 1a 완료 기준
- [ ] API 키가 OS 키체인에 저장되어 코드/파일/DB 어디에도 평문이 없다
- [ ] API 키 저장 시 경량 API 호출로 유효성이 즉시 검증된다
- [ ] 3개 AI 프로바이더(GPT-4o, Claude, Gemini) 중 1개 이상과 스트리밍 대화가 가능하다
- [ ] 메시지마다 토큰 수 + USD + KRW 비용이 표시된다
- [ ] DB가 SQLCipher AES-256으로 암호화되어 있다
- [ ] 모든 IPC 호출이 Zod 스키마로 검증된다
- [ ] 다크모드 기본 UI에서 대화 목록(핀/이름 변경)과 설정 화면이 동작한다
- [ ] 앱 언어를 한국어/영어로 전환할 수 있다

### Phase 1b 완료 기준
- [ ] `Alt+Space` 단축키가 어느 앱에서나 AIFlow 오버레이를 소환한다
- [ ] AI 페르소나 6종이 기본 내장되어 시스템 프롬프트가 실제로 변경된다
- [ ] 프롬프트 저장고에서 `{{변수}}` 슬롯이 동작한다
- [ ] 명령 팔레트(`Ctrl+K`)로 주요 기능에 접근 가능하다
- [ ] PDF 파일을 드래그앤드롭하면 AI가 내용을 읽고 답한다
- [ ] 자동 업데이터가 Ed25519 서명을 검증하고 업데이트를 적용한다
- [ ] DB 마이그레이션 실패 시 자동으로 백업에서 롤백된다

### Phase 2 완료 기준
- [ ] 2~3개 AI 동시 대화 후 나란히 비교하며 각 응답의 비용이 표시된다
- [ ] 스마트 라우팅이 복잡도를 분석하여 자동으로 AI를 선택한다

- [ ] LemonSqueezy 결제 후 Pro 기능이 즉시 활성화된다
- [ ] 배치 처리가 10개 파일을 순서대로 처리하고 결과를 저장한다

## 10. 강력 추천 추가 제안 v3.0 (리서치 기반)

### 🔴 즉시 적용 (Phase 1에 포함 강력 권장)
1. **글로벌 단축키 + 오버레이** — 어떤 경쟁사도 Windows에서 이걸 제대로 한 곳이 없음. Tauri `global-shortcut` 플러그인. Windows 최강 차별점.
2. **OS 키체인 + DB 암호화** — `tauri-plugin-keyring` + SQLCipher. 경쟁사 AnythingLLM, Open WebUI 모두 평문 저장. 보안 신뢰도 ★★★★★.
3. **AI 페르소나 시스템** — 시스템 프롬프트 세트 저장. 코딩/글쓰기/번역 용도별 전환. 구현 비용 낮고 사용자 감동 높음.
4. **실시간 비용 표시 (KRW 병행)** — 한국 사용자 필수. `₩XX` 형태 병행 표시. 타 서비스 어디도 KRW 표시 없음.
5. **AI 명령 팔레트 (Ctrl+K)** — Raycast처럼 자연어로 앱 제어. 기본 구현 복잡도 낮음, 사용자 "wow" 효과 ★★★★★.

### 🟡 Phase 2에 포함 강력 권장
6. **스마트 AI 라우팅** — 비용 절약 + 품질 유지의 핵심. LiteLLM 오픈소스 참고하여 Rust로 구현. 예상 비용 30~50% 절감.
7. **프라이버시 모드 (OpenRedaction)** — 570+ PII 패턴, 100% 로컬 JS. 한국 개인정보보호법(PIPA) 준수 마케팅 포인트. 경쟁사 전무.
8. **브라우저 확장 (Chrome Native Messaging)** — 웹에서 AIFlow로 컨텍스트 전달. Windows 등록: `chrome.runtime.sendNativeMessage`. 기술적 구현 보통.
9. **LemonSqueezy + 토스/네이버페이** — 한국 AI 도구 중 토스 결제 지원 없음. 진입 장벽 낮춤. 토스 87% 성장률, 한국 사용자 전환율 2~3배.
10. **배치 처리 큐** — 반복 작업 자동화. 경쟁사 전무. 번역/요약/분류 대량 처리. Tokio async queue로 구현.

### 🟢 Phase 3에 포함 권장
11. **RAG 개인 지식베이스** — LlamaIndex 또는 LightRAG. SQLite-vec 또는 LanceDB 로컬 벡터 DB. AnythingLLM 핵심 기능 내장.
12. **Voice 스택 (100% 로컬)** — Whisper.cpp(STT) + Ollama(LLM) + Piper(TTS). 완전 오프라인, 의료·법률 분야 특히 강력.
13. **AI 에이전트 + Human-in-the-Loop** — 중요 단계 사용자 승인. LibreChat 로드맵 1위. Tauri dialog API 활용.
14. **대화 브랜칭** — 특정 메시지에서 "다른 방향 탐색". 원본 유지. parent_conv_id 필드 이미 설계에 포함.
15. **플러그인 API 공개** — 서드파티 개발자 생태계. GitHub 오픈소스 코어 + 유료 플러그인 마켓.
16. **스마트 컨텍스트 주입** — 현재 포커스 앱·URL·파일을 AI에 자동 제공. Windows Accessibility API 활용.
17. **조건부 워크플로우 (if/else)** — GPT-4o 판단 → 분기 실행. 복잡한 자동화 가능.
18. **AI 응답 A/B 비교** — 같은 프롬프트를 두 AI에 보내 자동 비교. 프롬프트 최적화에 필수.
19. **앱 자동 업데이트** — Tauri updater. MSI 재설치 없이 업데이트. 사용자 이탈 방지.
20. **비용 예산 알림** — 월 예산($XX) 설정 → 80% 도달 시 알림. `tauri-plugin-notification` 활용.

## 12. 보안 아키텍처 (v3.1 신규)

### 보안 계층 모델
```
레이어 1 — 입력 보안
  API 키 → OS Credential Manager (절대 평문 저장 금지)
  사용자 입력 → Zod 스키마 검증 (IPC 경계 전체 적용)
  파일 드롭 → 파일 크기 제한 (최대 10MB), 확장자 화이트리스트

레이어 2 — 저장 보안
  SQLite → SQLCipher AES-256-CBC (마스터키: PBKDF2 25만 반복)
  PrivacyLog.masking_map → SQLCipher 위에 추가 AES-128 레이어
  로컬 파일 결과 → 사용자 지정 폴더만 허용 (allowed_paths 체크)

레이어 3 — 전송 보안
  AI API 호출 → 반드시 Rust 백엔드 경유 (JS 직접 호출 금지)
  모든 외부 통신 → TLS 1.3 필수 (reqwest default)
  MCP 서버 → allowed_paths 범위 외 파일 접근 차단
  브라우저 확장 → Chrome Native Messaging 전용 (WebSocket 금지)

레이어 4 — 런타임 보안
  스트리밍 토큰 → ipc::Channel (EventSystem 금지)
  Tauri CSP: default-src 'self'; connect-src 'none' (외부 JS 차단)
  전역 핫키 → 앱 종료 시 반드시 unregister() 호출
```

### Rate Limit 및 Circuit Breaker
| 상황 | 대응 전략 |
|------|----------|
| AI API 429 Too Many Requests | 지수 백오프 (1s → 2s → 4s → 8s, 최대 3회) |
| 3회 실패 | 폴백 체인의 다음 AI로 자동 전환 |
| 모든 AI 실패 | 사용자에게 "모든 AI 연결 실패, 나중에 다시 시도" 알림 |
| 월 예산 80% 도달 | 시스템 트레이 알림 + 앱 내 배너 |
| 월 예산 100% 초과 | AI 요청 차단 + "예산 초과" 경고 팝업 |

### 마스터키 로테이션 절차
```
1. 새 마스터키 생성 (OS 키체인)
2. DB: sqlcipher_export()로 평문 임시 덤프 (메모리 내)
3. 새 키로 DB 재암호화 (PRAGMA rekey)
4. 임시 덤프 즉시 소거
5. OS 키체인에서 구 마스터키 삭제
6. 검증: 새 키로 DB 열기 성공 확인
```
> 로테이션 주기: 사용자 요청 시 + 보안 이슈 감지 시 (자동 강제 로테이션 없음)

### API 키 탈취 대응 절차
1. 설정 → "API 키 비상 삭제" 원클릭으로 모든 키 OS 키체인에서 삭제
2. 앱 재시작 → 새 키 등록 안내
3. AI 공급자 사이트에서 직접 키 폐기 링크 안내 (OpenAI/Anthropic/Google)

## 14. PIPA / GDPR 컴플라이언스 (v3.1 신규)

> AIFlow는 **완전 로컬** 애플리케이션으로, 사용자 데이터를 Anthropic/OpenAI/Google 외부 서버에 전송하지 않는다.
> 단, AI API 호출 시 해당 AI 공급자의 개인정보처리방침이 적용됨을 사용자에게 고지한다.

### 앱 내 필수 고지 사항
1. **첫 실행 시**: "AI에 전송하는 내용은 해당 AI 공급자 서버에 전달됩니다. 개인정보 포함 여부를 확인하세요."
2. **프라이버시 모드 OFF 시**: "현재 프라이버시 모드가 꺼져 있습니다. 개인정보가 AI에 전달될 수 있습니다."
3. **브라우저 확장 최초 사용 시**: "현재 페이지의 텍스트가 AIFlow로 전송됩니다. 민감한 페이지에서는 주의하세요."

### 사용자 데이터 권리 구현
| 권리 | 구현 방법 |
|------|----------|
| 열람권 | 설정 → "내 데이터 내보내기" (JSON) |
| 삭제권 | 설정 → "모든 데이터 삭제" (DB + 키체인 전체 초기화) |
| 정정권 | 대화 편집 기능 (Phase 2) |
| 이동권 | JSON 내보내기 → 타 앱 호환 포맷 |

### 데이터 보존 정책 (기본값, 사용자 변경 가능)
| 데이터 유형 | 기본 보존 기간 | 위치 |
|------------|--------------|------|
| 대화 히스토리 | 영구 (사용자 수동 삭제) | SQLCipher DB |
